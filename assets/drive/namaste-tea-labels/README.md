# Namás-te - Etiquetas de Envases de Té

**Proyecto:** Diseño de etiquetas para envases de té orgánico (Té verde Bio Matcha Japonés)

**Tipo:** Diseño de packaging, etiquetado de producto

**Marca:** Namás-te - Tés e Infusiones Premium

## Resumen

Diseño integral de etiquetas para envases de té premium, incluyendo variantes rectangulares y circulares (7cm de diámetro) para diferentes tipos de presentación del producto.

## Características del diseño

- **Nombre del producto:** Té verde Bio Matcha Japonés
- **Subtítulo:** TES E INFUSIONES PREMIUM
- **Tamaño:** 100g (inferido del packaging)
- **Identidad visual:** Logo Namás-te (lágrima/loto estilizado)
- **Paleta:** Magenta, negro, verde
- **Sitio web:** www.namas-te.es
- **Certificación:** Producto orgánico/Bio

## Formatos

- Etiqueta rectangular (estándar)
- Etiqueta circular 7cm (para envases redondos)

Se incluyen 7 imágenes de mockups que muestran la aplicación de las etiquetas en productos finales y en contexto de tienda/presentación.
